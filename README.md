# Редактор MD

Небольшой редактор Markdown в одном HTML-файле. Без установки и сервера — работает офлайн.

## Запуск

Откройте `index.html` в браузере (лучше Chrome или Edge).

## Возможности

- Редактор и живой просмотр рядом (режимы: редактор / оба / просмотр)
- Открыть, сохранить, «сохранить как» — в Chrome/Edge сохраняет прямо в исходный файл
- Перетаскивание `.md` файла в окно
- Панель форматирования: жирный, курсив, заголовки, списки, чек-листы, цитаты, код, ссылки, таблицы
- Enter продолжает список, Tab / Shift+Tab — отступ
- Черновик автоматически сохраняется в браузере
- Экспорт в HTML, печать в PDF через Ctrl+P (печатается только просмотр)
- Светлая и тёмная тема, счётчик слов

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+N / Ctrl+O | Новый / открыть |
| Ctrl+S / Ctrl+Shift+S | Сохранить / сохранить как |
| Ctrl+B / Ctrl+I | Жирный / курсив |
| Ctrl+K | Ссылка |
| Ctrl+` | Код |

## Библиотеки

В `lib/` лежат [marked](https://github.com/markedjs/marked) 12.0.2 (разбор Markdown) и [DOMPurify](https://github.com/cure53/DOMPurify) 3.1.6 (очистка HTML).
